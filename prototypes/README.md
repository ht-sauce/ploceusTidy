# prototypes · 络雀原型目录

> 存放界面展示原型及其历史版本。技术选型未定，当前只有本说明，原型本体尚未开始。

## 用途

- 表达核心流程的界面形态：目录选择 → 扫描 → 方案预演 → 确认执行 → 结果与撤销。
- 作为实现前的评审与交接依据；生产代码不放在本目录。

## 目录约定

```
prototypes/
├── README.md          # 本文件：用途、规则、当前状态
├── <版本>-<主题>/      # 当前展示原型，如 20261021-organize-flow
└── archive/           # 历史版本，定稿冻结后移入
```

- 命名：kebab-case + 日期前缀 `YYYYMMDD-主题`；禁止 `final` / `最终版` / `new` 类命名。
- 版本只增不改：定稿后移入 `archive/`，并标注「仅参考，不作为依据」。

## 规则

1. **单一演进对象**：只维护一份最新展示原型，禁止并行多份造成多输出口漂移。
2. **原型自包含**：单个 HTML 文件直接打开即有完整样式，不依赖本地服务或构建。
3. **模拟数据**：原型不连接真实文件系统、不引生产依赖；文件操作以假数据表达。
4. **页面不出现实现细节**：不展示代码、配置键、内部路径；入口文案用中文。
5. **变更同批登记**：新增 / 改名 / 归档原型时，同批更新 [project-overview](../docs/project-overview.md) 与 `docs/spec/03-ui-interaction.md`【待建】。
