# 2026-10-30

## v0.3.0：应用内自动更新 + 一批交互/数据缺陷修复

**决策**：更新机制选官方 `tauri-plugin-updater`（A），不用自研 GitHub API + 静默安装（B）。
理由：现有 Authenticode 自签名只证明「谁打的包」，不能校验下载物是否被替换；B 的「退出 →
启动安装器 → 重启」时序自写最容易出事。中间选项（B + 钉证书指纹）要写 WinVerifyTrust 且
换证书即断更新链，否决。见 `docs/spec/08-adr.md` ADR-038。

**关键事实（后续会用到）**
- 更新签名私钥：`desktop/signing/updater.key`（无密码，`desktop/signing/` 已 gitignore），
  公钥写死在 `desktop/tauri.conf.json > plugins.updater.pubkey`。**私钥丢失 = 已装客户端只能手动重装一次**，
  需离线备份。构建时必须注入私钥，否则 `createUpdaterArtifacts` 会直接让 build 失败。
- Tauri 2 的 NSIS 更新产物**不是** `.nsis.zip`，而是安装包本体 + `*.exe.sig`（实测确认），
  `latest.json` 的 url 直接指向 exe。
- 发布：`pnpm tauri:build`（`scripts/tauri-build.mjs` 注入私钥 + 收集产物）、
  `pnpm release:publish`（生成 `latest.json` 并 gh 上传，`--dry-run` 只生成）。
- v0.3.0 必须手动装一次，它是第一个带公钥的版本。

**P0 数据安全**：加载失败曾会 `setHydrated(true)` 让 350ms 后的防抖保存用空快照清库。
现在前端加载失败进「不可写 + 常驻提示 + 重试」，Rust `scene_save` 增加空快照护栏
（`AppState.first_save`，只拦本进程第一次全量保存，第二次放行，配回归测试
`empty_first_save_does_not_wipe_existing_scene`）。

**其余修复**：弹窗打开时画布快捷键让位（`blockCanvasKeys`）；批量建线改 `connectMany` 一次记历史；
`importPaths` 引用稳定 + 拖入监听补 `disposed` 守卫 + 拒绝并发导入；内容弹窗按请求归属丢弃晚到响应；
`workspace_rebuild` 改用事务对象；导出媒体查重改名 + `file_name` 纯文件名校验；搜索筛选后索引夹取。

**验证**：pnpm test 33 项、cargo test 16 项、lint / format:check / build / check-spec 全过；
`pnpm tauri:build` 产出 `release/络雀_0.3.0_x64-setup.exe` 与签名。

## v0.3.1：清掉复核清单里的四项

- **迁移冻结写入**：`workspace_migrate` 全程持 `state.db` 写锁（读走 reader，界面不受影响），
  新连接/路径先准备好再一次性替换。锁顺序固定 db → reader → workspace → assets。
- **监听重挂**：`watcher.rs` 每 5s 摘掉已消失目录、每 60s 原地 unwatch+watch 重建句柄，

- **系统菜单句柄**：`platform.rs` 失败路径不再 `?` 提前返回，统一 DestroyMenu + CoTaskMemFree。

- 顺带：框选命中改用 `nodeRectOf`（与渲染口径一致）、tooltip 改为派生可见值（删除后不再残留）。
- 测试：cargo 17 项（新增迁移回归）；DbFixture 库名改为 `ploceus.db`（迁移按此名定位）。

## v0.3.2：连线层下沉，删掉避障路由

- 用户要求「连线 = -1，元素 2、空间 1，这样不用寻路」。**没有完全照搬**：
  空间底色是 `mixHex(color, 白, 0.94)` + `opacity: 1`，线放到空间下面会在空间内整条消失，
  而「同一空间内两个对象连线」是最常见场景。
- 最终层级：画布 0 → 空间框 1 → 连线 1.5 → 空间标题 1.6 → 元素 2（`CanvasBoard` Stage 子层顺序）。
  元素盖住线 → 不需要寻路；线仍在空间底色之上 → 不会消失。
- 删除：`routeEdgePath` / `astarWaypoints` / `simplifyWaypoints` / `smoothBezierPoints` /
  `segmentIntersectsRect` / `EdgeRoute` / `RoutePoint` / `obstaclesNear`（useVisibleScene、
  useCanvasInteractions、EdgeLayer、CanvasBoard 全部清理）。几何用例改写为锚点与自动选边，33 → 29 项。
- 若用户坚持 -1 观感，方案是把 GroupShape 拆成「底色层 + 边框层」，代价见 ADR-039 备选方案。




## v0.3.2 补丁：卡片底色与命中区（用户截图反馈两条）

- 症状：① 元素与连线叠在一起时按 G 建不了空间；② 连线看起来盖在元素上。
- 同一根因：`NodeShape` 没有整块底色/命中图形 → 卡片空白处点击穿透到下层连线的 16px 命中带，
  于是「点元素其实选中了连线」，selectedIds 为空 → createGroup 返回 null；同时卡片透明 →
  虚线从卡片里透出来。
- 修法：每张卡首个子元素加不透明 `Rect`（fill=tokens.surface, cornerRadius 6），
  既当命中区又挡住下层连线。顺带双击/拖动/悬停都覆盖整张卡片。
- 版本仍是 0.3.2（尚未发布，改动并入同一批）。
