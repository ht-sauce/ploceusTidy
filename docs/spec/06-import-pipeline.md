# 06-import-pipeline.md · 导入流水线

## 1. 触发

- 资源管理器拖入（文件/文件夹）。
- 资源管理器复制后 `Ctrl+V`（文件/文件夹）。
- 粘贴文字、截图/图片、URL。
- 重新关联缺失文件（选择器）。

## 2. 流程

```mermaid
flowchart LR
    A[拖入/粘贴] --> B[提取路径/文本/图片]
    B --> C[Rust 校验、stat、规范化]
    C --> D{文件路径已存在?}
    D -->|是| E[返回已有 nodeId]
    D -->|否| F[写 refs]
    F --> G[生成 nodes patch]
    E --> H[前端 locateNode]
    G --> I[事务落库]
    I --> J[前端应用 patch]
    H --> J
    J --> K[自动保存完成]
```

- 拖拽过程只显示投放位置；`drop` 后一次性提交。
- 文本/截图/URL 不去重；截图先写 `assets` 再生成引用。
- 文件夹只生成一个节点，不读取子项。

## 3. 批量与布局

- 多文件按投放点周围网格排布，避免重叠。
- 单批超过 50 个文件时显示轻量进度条，不弹模态框。
- 单批失败项汇总为一条可展开提示，包含路径与原因。
- 缩略图不在导入时生成，进入可见区域后异步加载。

## 4. 去重

- 文件/文件夹：`(kind, dedupe_key)` 唯一；重复返回已有节点。
- 同一批重复路径只保留一条。
- 文字、截图、URL 不参与去重。
- 重复导入提示「已存在，已定位」，并触发高亮。

## 5. 剪贴板

- 文件：Windows `clipboard-win::raw::get_file_list` 读取 `CF_HDROP`；macOS/Linux 后续按平台补。
- 文字：粘贴事件读取 `text/plain`；URL 用简单规则识别 `http/https`。
- 图片：Rust 读取剪贴板图片，写入 `dataWorkSpace/assets`，生成 `file` 引用（`path` 为工作空间内绝对路径）。
- 剪贴板格式不可识别时提示「不支持的内容类型」，不静默失败。

## 6. 失败语义

- 失败必须带：路径（若有）、操作、原因。
- 不因单个文件失败中断整批；失败项单独汇总。
- 数据库写入失败整体回滚，前端恢复上一版场景。

## 7. 性能

- Rust 批量 `stat`，限制并发；不读取文件内容。
- 大文件夹只取文件夹本身，不递归。
- 导入不生成缩略图、不计算内容哈希。
- 10 万引用时导入仍按批处理，避免长时间占用 UI 线程。
