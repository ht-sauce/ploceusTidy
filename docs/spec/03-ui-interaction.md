# 03-ui-interaction.md · 界面与交互

## 1. 窗口形态

| 形态 | 行为 |
| --- | --- |
| 标准窗口 | `decorations: false` 无边框；48px 自定义标题栏；默认 1000×700（按屏幕 62%×66% 收敛），最小 350×450 |
| 标题栏左侧 | 项目 logo + 「络雀」 |
| 标题栏中间 | 搜索框绝对居中，任意窗口尺寸下保持居中 |
| 标题栏右侧 | 新建文字、设置、操作说明（悬停显示快捷键）、最小化/最大化/关闭 |
| 拖动 | 标题栏空白处原生拖动窗口；按钮、输入框不触发拖动 |
| 调试 | F12 打开 WebView 开发者工具，release 构建也可用 |
| 桌面常驻 | 可选，默认关闭；窗口置底/桌面层，像桌面工具一样常驻 |
| 最小化/隐藏 | 暂停画布渲染、动画、缩略图请求；不退出进程 |
| 关闭 | 退出进程；默认不做托盘常驻 |

- 窗口控制按钮由应用自绘，但行为走 Tauri 窗口 API，不是纯视觉占位。
- 顶部搜索在任何窗口尺寸下都可见、可聚焦。
- 不做后台常驻服务；用户关闭即退出。

## 2. 布局

```text
┌──────────────────────────────────────────────────────────┐
│ [logo] 络雀        [搜索框]              [+ 设置 − □ ×] │ 48px
├──────────────────────────────────────────────────────────┤
│                                                          │
│  无限画布                                                │
│  系统图标 + 72×64 桌面图标格 / 收高分组框 / 有向边 / 标注点 │
│                                                          │
│                                     [详情面板 280px]     │
├──────────────────────────────────────────────────────────┤
│ 已保存 · 1,000 个引用                      − 82% +  适配 │ 28px
└──────────────────────────────────────────────────────────┘
```

- 无大侧栏、无顶部二级工具栏；画布占据最大面积。
- 详情面板只在通过右键「属性」或标注时出现，选中对象不会自动占用右侧空间。
- 迷你地图固定在画布右下角，默认显示；可关闭。
- 状态栏保留保存状态、引用数量、选中数量、连线/删除、缩放与适配。

## 3. 高密度与视觉基线

- 默认对象是 **Windows 桌面式图标格**：100% 缩放时每格 72×64px，顶部居中 32px 系统图标，下方名称 11px、最多两行，超出时压缩主体并优先保留后缀名；路径与完整内容通过 Ant Design Tooltip 悬停展示。
- 图标格默认透明，不画卡片底、边框或阴影；悬停显示 `hoverBg`，选中显示 `selectedBg` + 1px `primary` 边框。选择不能只依赖颜色，必须保留边框或焦点形态。
- 1440×900、100% 缩放、详情面板收起时，同屏至少 100 个引用；以实际同屏计数验收，不靠缩小字号制造密度。
- 图标直接使用系统风格：文件夹黄色、PDF 红白、Word 蓝白、Excel 绿白、DWG 蓝线、EXE 灰蓝、图片/视频/TXT/链接各自区分；系统图标不随 UI 主题重新着色，不自建卡通图标。
- 分组框只画 1px 虚线边界与小标题，不使用大面积色块。分组按内容收高：标题区 24px、内边距 8px、末行名称到底边 8px、相邻分组间距 16px；禁止固定等高、预留空行或拉伸图标格填满分组。
- 背景为浅色点阵；不做渐变、玻璃拟态、大圆角或装饰性留白。
- 缩放低于 50% 时降级为类型色点；50%–70% 显示简化系统图标与单行名称；70% 以上显示完整图标格。
- 缩略图只在可见、停留后加载；未就绪时显示系统类型图标，不阻塞布局。
- 缺失文件显示小徽标与「重新关联」，不隐藏对象。

## 4. 图标与对象

| 类型 | 内容 | 交互 |
| --- | --- | --- |
| 文件 | 32px 系统图标、最多两行名称；路径由 Tooltip 展示 | 双击打开原文件；右键菜单打开/定位/标注/属性/删除 |
| 文件夹 | 系统文件夹图标、最多两行名称；路径由 Tooltip 展示 | 双击在资源管理器打开；不展开子项；右键同上 |
| 图片 | 系统图片图标或就绪缩略图、最多两行名称 | 双击或右键预览 |
| 视频 | 系统视频图标、最多两行名称 | 双击用系统播放器打开；v1 不内嵌播放 |
| 链接 | 链接图标、最多两行标题；URL 由 Tooltip 展示 | 双击打开系统浏览器 |
| 文字 | 文字图标、最多两行标题；完整内容由 Tooltip 展示 | 双击在画布上内联编辑；空内容不覆盖原文 |
| 空间 | 按内容收高的虚线框 + 小标题 | 点击选中、拖动整体移动（含内部对象）、四向锚点连线、右键删除 |
| 标注 | 骑在对象下边框上的浅底文字牌 | 点击打开右侧标注面板；可搜索 |

- 所有对象默认使用同一网格尺寸；文字/链接也不做大卡片。
- 一个文件/文件夹只允许一个图标格；重复导入定位已有对象。
- 标注不占用独立图标格，文字牌压在下边框上并盖住框线，避免只显示色点看不到内容；浅底深字保证任何主题下都可读。
- 选中对象只做高亮与锚点提示，不自动打开右侧面板；文件操作一律走右键菜单。

## 5. 画布交互

- 平移：`空格 + 左键拖拽`；画布默认不可拖动，避免误操作。普通滚轮为纵向平移。
- 缩放：`Alt/Ctrl + 滚轮` 以指针为锚缩放；状态栏「适配」查看全部。
- 选择：单击选择；`Shift` / `Ctrl` 点击追加或取消；`左键拖拽空白`框选（Shift 追加）；`Ctrl+A` 全选。
- 选中状态保持：只有空白单击、`Esc` 或删除时才清除；鼠标移出画布、移出对象都不影响选中，右侧详情面板保持展开。
- 移动：拖动选中图标格；多选时整体移动。
- 删除：`Delete` / `Backspace` 删除对象与关联边/标注目标；`Ctrl+Z` 撤销；原文件不动。
- 连线：单选后拖动选中框四向圆点到目标对象或空间；或先选中多个对象按 `L` / 状态栏连线按钮批量建立有向边；箭头指向目标。点击连线选中，双击编辑标签，右键可改标签或删除。
- 标注：多选后通过右键菜单「添加标注」或详情面板入口，一次标注全部选中对象；标注文字牌显示在对象下边框上，点击即可编辑。
- 空间：框选对象后按 `G` / 状态栏按钮创建持久空间；点击空间框内空白即选中，拖动空间（含标题）会把内部对象一起移动；选中空间后拖四向锚点可与其他对象或空间连线；`Delete` / 右键删除只删框、保留对象。
- 右键菜单：节点、空间、连线的全部操作（打开、在资源管理器中定位、添加标注、属性、删除、编辑连线标签）统一收进自定义右键菜单；点击菜单外、`Esc` 或滚轮关闭。选择对象本身不再弹出右侧面板。
- 文字：`双击文字`进入画布内联编辑（原地输入，Esc 或点击空白结束，空内容不覆盖原文）；顶部「+」新建文字对象；粘贴文字在画布中心生成对象。
- 图标格名称优先保留后缀名：超出两行时压缩主体而不是后缀，避免同名不同后缀的文件无法区分。
- 迷你地图：右下角按内容包围盒绘制对象分布与视口框；点击或拖动迷你地图把该处移到视口中心。
- 顶部问号按钮：鼠标悬停展示全部画布快捷键，不占用画布空间。
- 渲染层为 Konva；缩放层级：低于 50% 色点；50%–70% 简化图标与单行名称；70% 以上完整图标格；边在低缩放时只显示与选中对象相关的部分。

## 6. 搜索与定位

- 顶栏搜索框常驻；`Ctrl/Cmd + K` 聚焦；输入即搜。
- 搜索建议面板浮在画布之上，不被工具栏或画布裁剪。
- 结果按类型展示：文件、文件夹、图片/视频、链接、文字、标注。
- 结果项显示系统图标、名称、路径/上下文摘要；只列少量结果，保持轻量。
- `↑/↓` 选择；`Enter` 定位对象：居中、适度缩放、1.4s 脉冲高亮；`Ctrl/Cmd + Enter` 打开原文件/浏览器/资源管理器定位；`Esc` 关闭。
- 无结果时提示「没有匹配；试试文件名、路径、文字或标注」。
- 搜索只查画布；不提供全盘搜索入口。

## 7. 重复导入

- 文件/文件夹路径命中已有引用：不新建对象，画布定位到已有对象并高亮。
- 提示用 Ant Design `message` 轻量提示：「已存在，已定位」，不弹模态框。
- 批量导入中的重复项合并为一次定位；多个重复项按最后一项定位。
- 文字、截图、URL 不去重，按正常新建。

## 8. 设置

- 使用 Ant Design `Modal` + `Switch`；底部提供文字「关闭」按钮。
- 外观：显示四套主题色板与名称，点击立即切换并保存；不提供自定义任意色，不跟随系统自动反色。
- 工作空间：显示 `dataWorkSpace` 实际路径、占用大小；「更改位置」走复制-校验-切换流程。
- 窗口：桌面常驻开关（默认关）、最小化暂停（默认开）。
- 数据：重建工作空间（危险操作，二次确认）；不提供云同步。
- 关于：版本、构建信息、开源许可。

## 10. 主题与语义色

### 10.1 原则

- 默认主题为灰雾紫；四套主题均为浅色办公主题，切换只改变 UI 语义色，不改变布局、字号、密度、文件图标或用户标注颜色。
- React/Ant Design 与 Konva 必须读取同一套语义令牌；组件禁止各自硬编码主题色。
- `primary` 只用于主按钮、焦点、选中边框与关键连线；顶栏和面板默认使用 `surface`，禁止整片铺设高饱和主色。
- 正文对比度至少 4.5:1，大字号与图形边界至少 3:1；选中、缺失、错误等状态必须同时具有边框、图标或文字提示，不只依赖颜色。

### 10.3 语义映射

| 令牌 | 用途 |
| --- | --- |
| `primary` / `primaryHover` | 主按钮、键盘焦点、选中边框、关键连线及其悬停态 |
| `selectedBg` / `hoverBg` | 图标格与搜索结果选中、悬停背景 |
| `canvasBg` / `surface` | 无限画布 / 顶栏、详情、弹窗、状态栏表面 |
| `border` | 输入框、面板、分组与分隔线；画布点阵使用同色系低对比度派生色 |
| `text` / `textSecondary` | 正文 `#30343A` / 次要文字 `#747A83`，四套主题共用 |
| `error` / `warning` / `success` | 固定语义色 `#C44B52` / `#9A6B24` / `#4F7663`，不随主题切换 |

### 10.4 切换行为

- 在「设置 → 外观」点击主题后立即生效，并将主题 ID 保存到 `app_meta.ui_theme`；重启恢复，缺失或非法值回退 `mist-purple`。
- 切换不得清空或重建场景，不得改变视口、缩放、选中对象、搜索内容、弹窗状态与撤销栈。
- 系统文件图标保持 Windows 原始颜色；文件类型色点、标注颜色、错误/警告/成功色不被主题覆盖。
- 暗色模式与高对比主题需要另做完整色板和对比度验证，不在本次四套浅色主题内自动派生。
