# 03-ui-interaction.md · 界面与交互

## 1. 窗口形态

| 形态 | 行为 |
| --- | --- |
| 标准窗口 | `decorations: false` 无边框；48px 自定义标题栏 |
| 标题栏左侧 | 项目 logo + 「络雀」 |
| 标题栏中间 | 搜索框绝对居中，任意窗口尺寸下保持居中 |
| 标题栏右侧 | 新建文字、设置、最小化/最大化/关闭 |
| 拖动 | 标题栏空白处原生拖动窗口；按钮、输入框不触发拖动 |
| 调试 | F12 打开 WebView 开发者工具，release 构建也可用 |
| 桌面常驻 | 可选，默认关闭；窗口置底/桌面层，像桌面工具一样常驻 |
| 最小化/隐藏 | 暂停画布渲染、动画、缩略图请求；不退出进程 |
| 关闭 | 退出进程；默认不做托盘常驻 |

- 窗口控制按钮由应用自绘，但行为走 Tauri 窗口 API，不是纯视觉占位。
- 顶部搜索在任何窗口尺寸下都可见、可聚焦。
- 不做后台常驻服务；用户关闭即退出。

## 2. 布局

```text
┌──────────────────────────────────────────────────────────┐
│ [logo] 络雀        [搜索框]              [+ 设置 − □ ×] │ 48px
├──────────────────────────────────────────────────────────┤
│                                                          │
│  无限画布                                                │
│  系统图标 + 176×28 紧凑行 / 分组虚线框 / 有向边 / 标注点 │
│                                                          │
│                                     [详情面板 280px]     │
├──────────────────────────────────────────────────────────┤
│ 已保存 · 1,000 个引用                      − 82% +  适配 │ 28px
└──────────────────────────────────────────────────────────┘
```

- 无大侧栏、无顶部二级工具栏；画布占据最大面积。
- 详情/标注面板在选中对象时占用右侧 280px，画布随之收缩，不覆盖内容。
- 迷你地图固定在画布右下角，默认显示；可关闭。
- 状态栏保留保存状态、引用数量、选中数量、连线/删除、缩放与适配。

## 3. 高密度与视觉基线

- 默认卡片是**紧凑文件行**：176×28px，左侧 16px 系统图标，只显示单行文件名；路径与完整内容通过 Ant Design Tooltip 悬停展示。
- 默认缩放下同屏 120–200+ 行（随窗口尺寸）；1000 条引用默认视图即可浏览大量内容。
- 图标直接使用系统风格：文件夹黄色、PDF 红白、Word 蓝白、Excel 绿白、DWG 蓝线、EXE 灰蓝、图片/视频/TXT/链接各自区分；不自建一套卡通图标。
- 分组框只画 1px 虚线边界与小标题，不使用大面积色块。
- 背景为浅灰点阵；卡片白底、细边框、极轻阴影；不做渐变、玻璃拟态或大圆角。
- 缩放低于 50% 时降级为 10×6px 色点；50%–70% 只保留名称；70% 以上显示完整行。
- 缩略图只在可见、停留后加载；未就绪时显示系统类型图标，不阻塞布局。
- 缺失文件显示小徽标与「重新关联」，不隐藏行。

## 4. 卡片与对象

| 类型 | 内容 | 交互 |
| --- | --- | --- |
| 文件 | 16px 系统图标、单行文件名；路径由 Tooltip 展示 | 双击打开原文件；详情面板中定位 |
| 文件夹 | 系统文件夹图标、单行名称；路径由 Tooltip 展示 | 双击在资源管理器打开；不展开子项 |
| 图片 | 系统图片图标、单行文件名；路径由 Tooltip 展示 | 双击或详情面板打开 Ant Design 图片预览 |
| 视频 | 系统视频图标、单行文件名 | 双击用系统播放器打开；v1 不内嵌播放 |
| 链接 | 链接图标、单行标题；URL 由 Tooltip 展示 | 双击打开系统浏览器 |
| 文字 | 文字图标、单行标题；完整内容由 Tooltip 展示 | 双击编辑；弹窗保存 |
| 分组框 | 虚线框 + 小标题 | 当前仅视觉占位；创建、移动、连线为后续批次 |
| 标注 | 5px 彩色圆点 | 点击打开右侧标注面板；可搜索 |

- 所有对象默认同一行高；文字/链接也不做大卡片。
- 一个文件/文件夹只允许一张行；重复导入定位已有行。
- 标注不占用独立卡片，只显示为行右上角的小圆点。

## 5. 画布交互

- 平移：拖拽空白处或滚轮缩放；状态栏「适配」按钮观察全部。
- 选择：单击选择；`Shift` / `Ctrl` 点击追加或取消；`Shift` + 空白处拖拽框选；`Ctrl+A` 全选。
- 移动：拖动选中行；多选时整体移动。
- 删除：`Delete` / `Backspace` 删除行与关联边/标注目标；`Ctrl+Z` 撤销；原文件不动。
- 连线：先选中多个对象（`Shift`/`Ctrl` 点击或 `Shift` 框选），按 `L` 或状态栏连线按钮，从第一个选中对象向其余对象建立有向边；箭头指向目标。
- 标注：多选后点击详情面板「添加标注」，一次标注全部选中对象；标注为目标集合。
- 分组框创建、锚点拖拽连线、边标签、边删除为后续批次；当前用「多选 + L」完成有向连线。
- 顶部「+」新建文字行；粘贴文字/截图在画布中心生成行；双击文字行编辑。
- 缩放层级：低于 50% 色点；50%–70% 简化行；70% 以上完整行；边在低缩放时只显示与选中对象相关的部分。

## 6. 搜索与定位

- 顶栏搜索框常驻；`Ctrl/Cmd + K` 聚焦；输入即搜。
- 结果按类型展示：文件、文件夹、图片/视频、链接、文字、标注。
- 结果项显示系统图标、名称、路径/上下文摘要；只列少量结果，保持轻量。
- `↑/↓` 选择；`Enter` 定位行：居中、适度缩放、1.4s 脉冲高亮；`Ctrl/Cmd + Enter` 打开原文件/浏览器/资源管理器定位；`Esc` 关闭。
- 无结果时提示「没有匹配；试试文件名、路径、文字或标注」。
- 搜索只查画布；不提供全盘搜索入口。

## 7. 重复导入

- 文件/文件夹路径命中已有引用：不新建行，画布定位到已有行并高亮。
- 提示用 Ant Design `message` 轻量提示：「已存在，已定位」，不弹模态框。
- 批量导入中的重复项合并为一次定位；多个重复项按最后一项定位。
- 文字、截图、URL 不去重，按正常新建。

## 8. 设置

- 使用 Ant Design `Modal` + `Switch`；底部提供文字「关闭」按钮。
- 工作空间：显示 `dataWorkSpace` 实际路径、占用大小；「更改位置」走复制-校验-切换流程。
- 窗口：桌面常驻开关（默认关）、最小化暂停（默认开）。
- 数据：重建工作空间（危险操作，二次确认）；不提供云同步。
- 关于：版本、构建信息、开源许可。

## 9. 浏览器调试

- `pnpm dev` 打开 `http://127.0.0.1:5173/`，仅用于前端调试；正式形态始终是桌面客户端。
- 入口文件：`client/App.tsx`、`client/components/TitleBar.tsx`、`client/components/CanvasBoard.tsx`、`client/components/FileTile.tsx`、`client/components/SystemIcon.tsx`。
- 浏览器模式使用 1000 条模拟引用验证密度、系统图标、搜索定位、标注与设置。
