# 05-file-reference-contract.md · 文件引用契约

## 1. 只读边界

- 应用不得修改、移动、重命名、删除用户文件。
- 读取、打开、定位仅限用户显式导入的引用；不递归扫描目录。
- 路径在 Rust 侧解析真实路径后校验；不跟随符号链接越界。
- 前端不持有文件系统权限；打开/定位命令只接受 `refId`，不接受任意路径。

## 2. 导入来源

| 来源 | 行为 |
| --- | --- |
| 资源管理器拖入文件 | 取绝对路径；`stat` 元数据；生成文件引用 |
| 资源管理器拖入文件夹 | 只生成一个文件夹引用，不枚举子项 |
| 资源管理器复制文件后粘贴 | Windows 通过 `clipboard-win::raw::get_file_list` 读 `CF_HDROP` |
| 粘贴文字 | 生成文字卡；不落文件 |
| 粘贴截图/图片 | 写入 `dataWorkSpace/assets`，生成图片节点；当前按路径引用 |
| 粘贴 URL | 生成链接卡；不抓取网页 |

- 批量导入按批处理；文件夹不递归。
- 同一批内重复路径先去重，再入库。

## 3. 路径规范化

- `path` 保存用户可见的绝对路径；`dedupe_key` 保存规范化真实路径（仅文件/文件夹）。
- Windows：大小写归一、统一斜杠、去除尾部分隔符；长路径按系统 API 支持处理。
- 解析失败或路径不存在：导入失败，带「路径 + 操作 + 原因」上报（HC-14）。
- 符号链接：记录用户导入的路径；打开/定位时校验真实路径，不越出显式引用。

## 4. 打开与定位

| 操作 | 实现 | 校验 |
| --- | --- | --- |
| 打开文件 | `tauri-plugin-opener::open_path` | 仅 `refId`；路径来自 DB |
| 在资源管理器中定位 | `reveal_item_in_dir` | 仅 `refId`；路径来自 DB |
| 打开 URL | `open_url` | 仅 `http/https`；URL 来自 DB |
| 打开图片 | 内置图片查看器（Ant Design `Image` 预览） | asset/ref 路径来自 DB |
| 视频 | 系统默认播放器 | 仅 `refId` |

- 文件缺失时禁用打开/定位，显示「重新关联」。
- 重新关联：原生文件选择器选中新路径；更新 `refs.path` / `dedupe_key`；卡片位置不变。

## 5. 缩略图与图标

- Windows 使用系统 Shell：
  - `IShellItemImageFactory::GetImage` 获取与资源管理器一致的缩略图。
  - 失败时回退 `SHGetFileInfoW` 图标。
  - EXE、文件夹、图片、视频、Office/PDF 等由系统提供者决定；不自建图标集。
- 剪贴板图片按扩展名保存；缩略图生成后续补。
- 图片预览当前由 `preview_ref` 返回 data URL（≤24MB）；后续可改为自定义协议按 `refId` 查库，避免大图 base64 传输。
- 仅对可见卡片请求缩略图；同屏并发受限。

## 6. 文件缺失

- 启动后分批惰性 `stat`，不阻塞画布首屏。
- `refs.is_exists=0` 时卡片显示缺失徽标；搜索仍可命中。
- 提供「重新关联」和「从画布移除」；移除只删引用，不动原文件。
- 失败列表按「路径 + 原因」展示，不静默跳过。

## 7. 隐私

- 不读取文件内容用于上传；缩略图只在本地生成。
- 不访问网络；URL 只交给系统浏览器。
- 剪贴板只在用户粘贴时读取。

## 8. 非目标

- 不提供移动/改名/删除/回收站。
- 不提供递归目录浏览、全盘搜索、文件内容索引。
- 不提供文件内容编辑。
