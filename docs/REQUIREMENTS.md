# REQUIREMENTS.md · 络雀需求基线

> 本文件是 v1 的需求基线。范围与验收以本文件为准，架构实现见 `spec/`。需求变更先改本文件，再同步 `00-overview.md` 与相关 spec。

## 1. 产品定位

络雀是一个**本地文件、文字与链接的空间索引画布**。用户把散落在电脑里的文件、截图、文字、URL 拖入或粘贴到一张无限画布上，按项目分组、连线、标注，并通过顶部搜索快速定位。

产品只保存引用：文件与文件夹保存路径，双击打开原文件；应用不移动、不改名、不删除用户文件。

一句话：**放进来、摆一起、连起来、标出来、搜得到、点得开。**

## 2. 目标用户与场景

- 工程材料、方案、图纸、合同等文件量大，目录结构复杂，但用户需要用空间关系梳理项目。
- 个人项目：装修、旅行、研究、投标、课程等，需要把文件、截图、网页链接放在一起。
- 文件量：v1 目标是数千到一万以内流畅；架构容量目标为十万级引用。

## 3. 设计原则

1. **只读引用**：原文件不动；应用只存路径与展示元数据。
2. **零心智负担**：导入不弹窗；重复文件自动定位；搜索即定位；自动保存；删除可撤销。
3. **单画布**：v1 一张画布，用分组框组织项目；多画布后置。
4. **纯本地**：不接云端、不上传文件内容或元数据；URL 仅交给系统浏览器打开。
5. **失败可见**：导入失败、文件缺失、路径失效必须带路径与原因呈现。
6. **高密度**：系统图标 + 紧凑行；数千文件可同屏浏览；远景降级为色点。
7. **简单**：无边框窗口、顶部搜索常驻、不过度设计；默认视图不做大缩略图卡片。

## 4. 功能需求

| 编号 | 需求 | 说明 |
| --- | --- | --- |
| R-01 | 无限画布 | 平移、缩放、框选、多选、移动、层级；支持数千节点流畅，容量目标十万级 |
| R-02 | 文件导入 | 拖入文件/文件夹；粘贴资源管理器复制的文件；只取路径，不递归目录 |
| R-03 | 非文件导入 | 粘贴文字、截图/图片、URL；文字与截图不去重；截图落本地资源 |
| R-04 | 文件去重 | 文件/文件夹按规范化真实路径去重；重复导入只定位已有卡片，不新建 |
| R-05 | 卡片类型 | 文件、文件夹、图片、视频、链接、文字、分组框；默认 176×28 紧凑行，16px 系统图标，路径悬停显示 |
| R-06 | 打开与定位 | 文件打开原文件；文件夹在资源管理器打开；URL 打开浏览器；图片内置查看器 |
| R-07 | 连线 | 有向边、箭头；v1 通过多选 + `L` / 状态栏按钮从第一个选中对象连向其余对象；锚点拖拽、边标签、边删除为后续 |
| R-08 | 标注 | 多选后添加结构化标注；颜色、文本、可搜索；不做自由涂鸦 |
| R-09 | 搜索 | 顶部固定搜索框；模糊子串匹配；结果定位并高亮；支持键盘操作 |
| R-10 | 重复导入定位 | 已有文件再次拖入/粘贴时，直接居中、缩放、高亮已有卡片 |
| R-11 | 文件缺失 | 启动/聚焦时惰性校验；缺失卡片显示徽标；支持重新关联 |
| R-12 | 窗口形态 | 无边框自定义标题栏 + 项目 logo；顶部搜索常驻；标准/紧凑模式；关闭即退出 |
| R-13 | 渲染生命周期 | 最小化/隐藏/失焦时暂停渲染与动画；不可见节点不创建绘制对象 |
| R-14 | 本地工作空间 | `dataWorkSpace` 存放 SQLite、资源、缩略图；默认安装目录，可在设置中迁移 |
| R-15 | 数据恢复 | 不做复杂容灾；SQLite WAL + 事务；异常时提供重建工作空间 |
| R-16 | 安全边界 | 只读；路径来自显式导入；打开/定位只接受引用 ID；不跟随符号链接越界 |
| R-17 | 高密度界面 | 默认缩放下同屏 120–200+ 行（随窗口尺寸）；远景 LOD 色点；不做大缩略图卡片与装饰性留白 |

## 5. 搜索范围与匹配规则

- 范围：画布内已导入的文件名、路径、URL、文字内容、标注、分组框标题、连线标签。
- 不做全盘搜索，不索引文件内容，不做 OCR。
- 匹配：NFKC 归一、大小写归一、斜杠统一、子串匹配；拼音首字母后续可选。
- 排序：名称精确 > 名称前缀 > 名称子串 > 路径 > 标注/文字。
- 交互：`Ctrl/Cmd + K` 聚焦；`Enter` 定位卡片；`Ctrl/Cmd + Enter` 打开原文件/在资源管理器定位；`Esc` 关闭结果。

## 6. 去重规则

| 类型 | 是否去重 | 依据 |
| --- | --- | --- |
| 文件 | 是 | 规范化真实路径 |
| 文件夹 | 是 | 规范化真实路径 |
| 文字 | 否 | 用户可能有意重复 |
| 剪贴板截图/图片 | 否 | 生成成本低、内容可能相似；存本地副本 |
| URL | 否 | 按用户输入保留，避免误合并 |

- 去重由数据库约束保证，不靠 UI 判断。
- 重复导入返回已有节点，前端只执行定位。
- 一个引用只允许一张卡片；跨项目关系用连线/标注表达。

## 7. 非目标（v1 不做）

- 云端同步、账号、协作、遥测。
- AI 分类、内容理解、OCR、自动打标。
- 移动、改名、删除用户文件。
- 递归扫描目录、全盘索引、文件内容索引。
- 画布内嵌视频播放、自由手绘、多画布。
- 复杂容灾、自动备份、多副本。
- macOS/Linux 首发；v1 先 Windows。

## 8. 里程碑与验收

| 阶段 | 交付 | 验收 |
| --- | --- | --- |
| M0 | 需求/架构/ADR/原型；Tauri spike | 拖入取路径、复制文件粘贴、SQLite、画布、opener 跑通；ADR-001 验证通过 |
