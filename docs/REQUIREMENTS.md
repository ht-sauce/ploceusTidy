# REQUIREMENTS.md · 络雀需求基线

> 本文件是 v1 的需求基线。范围与验收以本文件为准，架构实现见 `spec/`。需求变更先改本文件，再同步 `00-overview.md` 与相关 spec。

## 1. 产品定位

络雀是一个**本地文件、文字与链接的空间索引画布**。用户把散落在电脑里的文件、截图、文字、URL 拖入或粘贴到一张无限画布上，按项目分组、连线、标注，并通过顶部搜索快速定位。

产品只保存引用：文件与文件夹保存路径，双击打开原文件；应用不移动、不改名、不删除用户文件。

一句话：**放进来、摆一起、连起来、标出来、搜得到、点得开。**

## 2. 目标用户与场景

- 工程材料、方案、图纸、合同等文件量大，目录结构复杂，但用户需要用空间关系梳理项目。
- 个人项目：装修、旅行、研究、投标、课程等，需要把文件、截图、网页链接放在一起。
- 文件量：v1 目标是数千到一万以内流畅；架构容量目标为十万级引用。

## 3. 设计原则

1. **只读引用**：原文件不动；应用只存路径与展示元数据。
2. **零心智负担**：导入不弹窗；重复文件自动定位；搜索即定位；自动保存；删除可撤销。
3. **单画布**：v1 一张画布，用空间（分组框）组织项目；多画布后置。
4. **纯本地**：不接云端、不上传文件内容或元数据；URL 仅交给系统浏览器打开。
5. **失败可见**：导入失败、文件缺失、路径失效必须带路径与原因呈现。
6. **高密度**：Windows 桌面式系统图标网格；卡片高度自适应；数千文件可同屏浏览；缩小后仍显示完整对象。
7. **简单**：无边框窗口、顶部搜索常驻、不过度设计；默认视图不做大缩略图卡片。

## 4. 功能需求

| 编号 | 需求 | 说明 |
| --- | --- | --- |
| R-01 | 无限画布 | 平移、缩放、框选、多选、移动、层级；支持数千节点流畅，容量目标十万级；对象之间、空间之间不允许重叠，拖动时显示对齐参考线并自动吸附边缘/中心，新建与导入对象自动避让已有对象 |
| R-02 | 文件导入 | 拖入文件/文件夹；粘贴资源管理器复制的文件；只取路径，不递归目录 |
| R-03 | 非文件导入 | 粘贴文字、截图/图片、URL；文字与截图不去重；截图落本地资源 |
| R-04 | 文件去重 | 文件/文件夹按规范化真实路径去重；重复导入只定位已有卡片，不新建；同一次拖放/粘贴重复派发的事件在短窗口内合并，避免「已存在」刷屏 |
| R-05 | 对象类型 | 文件、文件夹、图片、视频、链接、文字、空间（分组框）；快捷方式（`.lnk`）按可执行对象处理并显示 Shell 目标图标；默认 72px 宽图标格、高度随名称行数自适应，32px 系统图标，名称最多两行且优先保留后缀名，路径悬停显示 |
| R-06 | 打开与定位 | 文件打开原文件；文件夹在资源管理器打开；URL 打开浏览器；图片内置查看器；入口为双击与右键菜单 |
| R-07 | 连线 | 有向虚线箭头，颜色可调，线宽明显可见；选中后按线条颜色外发光；节点与空间都可作为端点；单选后拖拽四向锚点连线，或多选 + `L` / 状态栏按钮批量连线；点击选中、双击编辑标签、右键改色或删除 |
| R-08 | 标注 | 多选后添加结构化标注；标注以文字牌骑在对象下边框上展示并可点击编辑；文字牌颜色跟随主题主色；可搜索；不做自由涂鸦 |
| R-09 | 搜索 | 顶部固定搜索框；模糊子串匹配；名称支持拼音首字母；范围含对象、标注、空间标题与连线标签；结果定位并高亮；支持键盘操作 |
| R-10 | 重复导入定位 | 已有文件再次拖入/粘贴时，直接居中、缩放、高亮已有卡片 |
| R-11 | 文件缺失 | 启动/聚焦时惰性校验；缺失卡片显示徽标；支持重新关联 |
| R-12 | 窗口形态 | 无边框自定义标题栏：logo + 居中搜索 + 最小化/最大化/关闭；标题栏空白处可拖动窗口；F12 打开调试器；关闭即退出 |
| R-13 | 渲染生命周期 | 画布按需重绘、无持续动画；离屏节点不创建绘制对象；窗口最小化或隐藏时按设置暂停缩略图加载与画布动画，恢复后继续 |
| R-14 | 本地工作空间 | `dataWorkSpace` 存放 SQLite、资源、缩略图；默认安装目录，可在设置中迁移 |
| R-15 | 数据恢复 | 不做复杂容灾；SQLite WAL + 事务；异常时提供重建工作空间 |
| R-16 | 安全边界 | 只读；路径来自显式导入；打开/定位只接受引用 ID；不跟随符号链接越界 |
| R-17 | 高密度界面 | 72px 宽图标格、高度随名称行数与标注自适应（最多两行）；1440×900、100% 缩放、详情收起时同屏 ≥100 个引用；空间按内容收高；不做远景色点降级，缩小后仍绘制完整对象；不做大缩略图卡片与装饰性留白 |
| R-18 | 可切换主题 | 默认灰雾紫，可选石板蓝灰、青禾灰绿、石墨灰；统一语义色，切换即时生效并本地保存，不改变视口、缩放、选中与撤销栈 |
| R-19 | 右键菜单 | 画布对象、空间、连线的操作统一收进自定义右键菜单（打开、定位、跳转关联对象、标注、属性、重命名、改色、删除）；文件/文件夹额外提供「系统右键菜单…」，调用 Windows 原生 Shell 菜单并保留第三方扩展；菜单过长时在容器内滚动；选择对象不再自动弹出右侧面板，属性面板由菜单打开 |
| R-20 | 空间 | 框选对象后可创建持久空间；对象拖入空间自动成为成员、拖出自动脱离；空间与内部对象一起移动，空间本身可参与连线；空间标题即空间标注，可重命名并自动编号；右键「自动整理空间」按当前阅读顺序排成网格并收高空间；删除空间只删框保留对象；空间之间不允许重叠 |
| R-21 | 空间与连线配色 | 空间、连线可分别通过取色器改色并持久化；多个空间默认使用可区分的调色板轮换；空间使用实线框并用高对比主色，内部铺极浅同色底；选中空间时按空间颜色外发光；连线使用虚线 |
| R-22 | 关联跳转 | 有连线的对象/空间右键可「跳转到关联对象」；只有一个邻居时直接定位，多个邻居时弹出选择列表 |
| R-23 | 画布清晰度 | Konva 渲染倍率不低于 2；任意缩放都绘制完整对象；主题边框与次要文字提高对比度 |

## 5. 搜索范围与匹配规则

- 范围：画布内已导入的文件名、路径、URL、文字内容、标注、空间标题、连线标签。
- 不做全盘搜索，不索引文件内容，不做 OCR。
- 匹配：NFKC 归一、大小写归一、斜杠统一、子串匹配；名称额外生成拼音首字母（如 `xmcl` 命中「项目材料」）。
- 排序：名称精确 > 名称前缀（含拼音首字母前缀）> 名称子串（含拼音首字母）> 路径 > 标注/空间/连线文本。
- 交互：`Ctrl/Cmd + K` 聚焦；`Enter` 定位卡片/空间/连线；`Ctrl/Cmd + Enter` 打开原文件或资源管理器定位（空间/连线无原文件，退化为定位）；`Esc` 关闭结果。

## 6. 去重规则

| 类型 | 是否去重 | 依据 |
| --- | --- | --- |
| 文件 | 是 | 规范化真实路径 |
| 文件夹 | 是 | 规范化真实路径 |
| 文字 | 否 | 用户可能有意重复 |
| 剪贴板截图/图片 | 否 | 生成成本低、内容可能相似；存本地副本 |
| URL | 否 | 按用户输入保留，避免误合并 |

- 去重由数据库约束保证，不靠 UI 判断。
- 重复导入返回已有节点，前端只执行定位。
- 一个引用只允许一张卡片；跨项目关系用连线/标注表达。

## 7. 非目标（v1 不做）

- 云端同步、账号、协作、遥测。
- AI 分类、内容理解、OCR、自动打标。
- 移动、改名、删除用户文件。
- 递归扫描目录、全盘索引、文件内容索引。
- 画布内嵌视频播放、自由手绘、多画布。
- 视频封面提取；图片预览自定义协议（双击预览沿用当前 data URL 方案）。
- 复杂容灾、自动备份、多副本。
- macOS/Linux 首发；v1 先 Windows。
