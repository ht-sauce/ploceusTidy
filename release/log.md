# 发布日志

各版本更新内容。最新版本与安装包见 [GitHub Releases](https://github.com/ht-sauce/ploceusTidy/releases/latest)，也可直接从本目录下载当前安装包。

## v0.3.1（2026-10-30）

### 修复

- **迁移工作空间期间可能丢最后一笔改动**：拷贝数据库到切换连接之间没有冻结写入，拷贝期间任何一次防抖保存都会落到即将被丢弃的旧库上，切换后前端仍以为「已保存」。现在整段迁移持有写锁（读走独立连接，界面照常），新连接与路径先全部准备好并校验，最后一次性替换，失败保持原状。新增回归测试锁死「迁移后读写都指向新库」。
- **目录被删除或改名后监听静默失效**：底层句柄失效而 `watched` 仍记着该路径，目录重新建回来后也不会重挂，之后该目录的增删改全部不刷新卡片状态。现在每 5 秒摘掉已消失的目录，并每 60 秒原地重建一次监听句柄（兜住「删掉又在同一路径建回」）。
- **系统右键菜单异常路径泄漏句柄**：`CreatePopupMenu` 失败时漏放 PIDL；执行 Shell 命令失败时 `?` 提前返回，同时漏掉 `DestroyMenu` 与 `CoTaskMemFree`——反复触发会累积 USER 句柄，最终连菜单都弹不出来。
- **视口内超过 60 张待加载图片时后续批次不加载**：`visibleNodes` 引用不变导致 effect 不再重跑，第 61 张之后永远没有缩略图；现在每轮加载完主动推进下一轮。
- **框选命中与渲染高度不一致**：命中判定用存储高度，带标注或名称换行的卡片底部选不中、矮卡片上方多出一段「看不见却能选中」的区域；改用与渲染、碰撞一致的展示矩形。
- **悬浮提示指向已删除对象**：对象被删后 Konva 不补发 `mouseleave`，提示会留在屏上；改为按当前场景派生可见值。

## v0.3.0（2026-10-30）

### 新增

- **应用内自动更新**：启动后自动检查（24 小时一次，`app_meta` 节流），也可在「设置 → 关于」手动检查；发现新版本时标题栏设置按钮显示红点，关于区显示版本、发布说明与下载进度；点「下载并安装」后**先落库再重启**完成升级，落库失败即中止，不会丢最后一笔改动。更新包走 minisign 验签，只接受内置公钥签过的包（公钥固定在客户端，私钥在 `desktop/signing/` 不入库）。
- **发布链路**：`pnpm tauri:build` 自动注入更新签名私钥并产出安装包签名；`pnpm release:publish` 生成 `latest.json` 并把安装包、`.exe.sig` 以 ASCII 名上传到 GitHub Releases（`--dry-run` 只生成不上传）。

### 修复

- **场景加载失败会清空数据库**（严重）：加载失败时不再把空画布当成合法场景进入可写状态，界面常驻提示并给「重试」；Rust 侧 `scene_save` 增加护栏，本进程首次保存若快照为空而库里已有数据，直接拒绝并说明原因。
- **`Ctrl+S` 谎报「已保存」**：场景没加载完时 `flush` 并未写库，现在明确提示「本次未写入」。
- **弹窗打开时画布快捷键仍在生效**：设置、内容管理、取色、跳转选择、文字/富文本弹窗打开时，`Delete` 会删掉背后的对象、方向键会微调、`G`/`L` 会建空间或连线——现在模态期间画布快捷键一律让位。
- **搜索框 Esc 连带清空画布选中**；搜索切换类型筛选后高亮索引越界、按 `Enter` 无响应。
- **一次 `L` 建多条连线要按多次撤销**：批量建线改为一次记历史、一次写状态，撤销一次即可整体回退。
- **拖入监听随渲染累积**：`importPaths` 每次渲染换引用导致拖放订阅反复重装，且清理时拿不到 `dispose`，旧监听摘不掉；现在回调引用稳定并补上 `disposed` 守卫，同一文件也不会在下次渲染被重复导入。
- **并发导入互相打断**：上一批未结束时再粘贴，进度条会被覆盖、先结束的那个还会清掉仍在跑的 job 的进度与「取消」按钮；现在直接拒绝并发并在结束时只清理自己的 job。
- **关掉内容弹窗又被打开**：正文是懒加载的，晚到的 `node_body` 响应会把刚取消的弹窗重新弹出；现在按请求归属校验，取消即作废。
- **重建工作空间后保存全失败**：改用事务对象（失败即回滚），不再出现「连接卡在事务里，之后每次保存都报错」。
- **导出覆盖用户文件**：富文本媒体导出改为查重改名并同步改写正文引用；单条导出的 `file_name` 增加纯文件名校验，拒绝目录分隔符与绝对路径。
