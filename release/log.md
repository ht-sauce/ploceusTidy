# 发布日志

各版本更新内容。最新版本与安装包见 [GitHub Releases](https://github.com/ht-sauce/ploceusTidy/releases/latest)，也可直接从本目录下载当前安装包。

## v0.1.3（2026-10-28）

### 新增

- **撤销与重做**：撤销栈 30 步，`Ctrl+Z` 撤销、`Ctrl+Shift+Z` / `Ctrl+Y` 重做；覆盖移动、微调、改色、改名、连线、标注、导入、自动整理与删除（此前只有删除与整理可撤销一步）。
- **`Ctrl+S` 立即保存**：主窗口与文字/富文本弹窗内均生效；弹窗内保存**不关闭弹窗**，方便边写边看，「保存」按钮才写回并关闭；标注编辑框用 `Ctrl+S` / `Ctrl+Enter` 保存。
- **关窗前强制落库**：点 ❌ 会先把待保存内容写进库再关窗；保存失败则不关闭并提示原因，不再出现「改完就关、最后一笔丢了」。
- **真实保存状态**：状态栏由写死的「已保存」改为「保存中 / 已保存 / 保存失败」，失败转红。
- **方向键微调**：选中对象后 `↑↓←→` 移动 1px，`Shift + 方向键` 10px；连续按键合并为一步撤销。
- **边缘自动平移**：拖动对象/空间到视口边缘 56px 内，画布按帧跟着走，大画布不必「松手 → 平移 → 再拖」。
- **校验引用**：设置 →「立即校验」全量比对原文件，文件被搬走后不必重启应用。
- **扩展样式生效**：属性面板里的 `{"accent":"#..."}` 现在真的画成卡片描边（此前只存不用）。

### 优化

- **标注排版**：标注文字牌不再压在卡片下边框线上，独占底部 18px 区域（距框线 5px、字号 10），多标注时显示「+N」。
- **空间整理**：只在对象进出空间时按网格整理；空间内部拖动压到成员只推开被拖的那一个，不再重排整组（ADR-031）。
- **导入失败**：从只报第一条改为逐条弹窗列出路径与原因（最多 8 条 + 总数）。
- **大画布性能**：rbush 空间索引改为常驻 + 按矩形增删，不再每次场景变化全量重建；缩略图缓存加 400 张上限；迷你地图补上 memo。
- **滚轮方向**：横纵分别平移，触摸板横向滑动不再变成纵向。
- **适配画布**：空间与空间外的游离对象一起纳入包围盒。
- **编辑弹窗**：取消时若有未保存改动会先确认，整篇内容不会被 Esc 抹掉。

### 修复

- `Ctrl+S` 会误弹出设置面板（单字母快捷键未排除修饰键）。
- 拖动松手后对齐参考线可能残留。
- 设置里的版本号写死为 0.1.1，现改由构建期从 `package.json` 注入。

### 移除

- 无入口的父子挂载逻辑（`mountNode` / `unmountNode` / `parent_node_id` 客户端读写）与 Rust `node_get` 命令；数据库列保留待后续启用。

### 验证

- `pnpm lint`、`pnpm format:check`、`pnpm check-spec`、`pnpm build`、`cargo test`（10 项）全绿；NSIS 安装包构建与签名通过。

## v0.1.2（2026-10-27）

### 新增

- **富文本媒体本地上传**：富文本编辑器支持插入本地图片与视频，经 Tauri Raw IPC 二进制直传（不经 base64）保存到工作空间 `dataWorkSpace/assets/`，文件名由 UUID 生成；正文 HTML 只存 `assets/<文件名>` 相对引用，工作空间迁移后无需改写。
- **粘贴直传**：在编辑器内 `Ctrl+V` 粘贴截图即自动上传落盘，与「上传图片」按钮同一通道。

### 优化

- 编辑器移除「网络图片」「网络视频」入口，媒体一律本地化，保持纯本地、零外部请求。
- 新增 `richasset` 自定义协议回读媒体（含 HTTP Range 分片），视频可拖动进度条；图片上限 20MB、视频上限 100MB，扩展名走白名单校验（png/jpg/jpeg/webp/gif/bmp/mp4/webm/ogg）。

### 修复与验证

- 前后端同时校验媒体大小与非空；兼容 Windows BMP MIME。
- 媒体读写解析真实路径，拒绝越出工作空间或资产目录；仅含图片/视频的富文本也可保存。
- 静态检查、前端与 release 构建、Rust 10 项测试、内容保存 5 项回归通过；真机验收由用户于 2026-10-27 确认完成。

## v0.1.1（2026-10-26）

### 新增

- **富文本卡片**：顶部「+」→「富文本」创建，双击弹出 wangEditor-next 编辑器（按需加载，不占首屏），正文以 HTML 持久化，支持加粗、标题、列表、引用、链接等格式。
- **文件拖出**：画布中按住 `Ctrl + 左键拖拽` 文件卡片到外部程序（VS Code、资源管理器等），以 OLE 拖出原文件。
- **复制原文件**：右键菜单「复制文件」（Windows `CF_HDROP`），到资源管理器粘贴即得原文件。

### 优化

- 「+」改为下拉菜单：新建时先选择「纯文本 / 富文本」。
- 新建文本与富文本按鼠标在画布上的最后位置落点，并自动归入所在空间。
- 文本编辑统一改回弹窗，画布内不再进入内联编辑态。
- NSIS 安装包中英双语：首次安装弹出语言选择框（中文(简体) / English），默认跟随系统语言。

### 修复

- 添加标注导致页面空白：DetailsPanel 渲染期 setState 死循环；右键「添加标注」全链路回归验证通过。

### 并入的 10-25 热修内容

- 提升文字对比度：画布与界面正文改为纯黑 `#000`，对象名称字号 11 调至 12。
- 空间拖入接纳：对象拖出后可再拖回，落点在空间内即放入并自动整理成员。
- 空间手动调框：选中空间拖四角可拉大/缩小框，成员进出仍按内容自动贴合。
- 单实例运行：重复启动只激活已有窗口，不再开多个实例。

## v0.1.0（2026-10-25）

首个公开版本：把文件、截图、文字、URL 放到一张无限画布上，分组、连线、标注、搜索定位；只保存引用，原文件不动。

- **导入**：拖入 / 粘贴文件、文件夹、文字、URL、截图；按真实路径去重，重复导入自动定位。
- **组织**：无限画布平移缩放、框选多选、空间（分组框）、拖动对齐吸附、对象与空间不重叠、空间自动整理。
- **关系**：有向连线（锚点拖拽、批量连线、标签、取色），右键跳转关联对象。
- **标注**：多选批量标注，空间标题即标注。
- **搜索**：拼音首字母 + 模糊搜索，覆盖对象、标注、空间标题与连线标签，回车直接定位。
- **文件**：双击用系统默认程序打开、资源管理器中定位、Windows 原生 Shell 右键菜单（含第三方扩展）、缺失文件校验与重新关联。
- **外观**：四套浅色主题；窗口最小化自动暂停渲染。
- **隐私**：纯本地运行，无云端、无遥测、无外部请求。
