# 发布日志

各版本更新内容。最新版本与安装包见 [GitHub Releases](https://github.com/ht-sauce/ploceusTidy/releases/latest)，也可直接从本目录下载当前安装包。

## v0.1.1（2026-10-26）

### 新增

- **富文本卡片**：顶部「+」→「富文本」创建，双击弹出 wangEditor-next 编辑器（按需加载，不占首屏），正文以 HTML 持久化，支持加粗、标题、列表、引用、链接等格式。
- **文件拖出**：画布中按住 `Ctrl + 左键拖拽` 文件卡片到外部程序（VS Code、资源管理器等），以 OLE 拖出原文件。
- **复制原文件**：右键菜单「复制文件」（Windows `CF_HDROP`），到资源管理器粘贴即得原文件。

### 优化

- 「+」改为下拉菜单：新建时先选择「纯文本 / 富文本」。
- 新建文本与富文本按鼠标在画布上的最后位置落点，并自动归入所在空间。
- 文本编辑统一改回弹窗，画布内不再进入内联编辑态。
- NSIS 安装包中英双语：首次安装弹出语言选择框（中文(简体) / English），默认跟随系统语言。

### 修复

- 添加标注导致页面空白：DetailsPanel 渲染期 setState 死循环；右键「添加标注」全链路回归验证通过。

### 并入的 10-25 热修内容

- 提升文字对比度：画布与界面正文改为纯黑 `#000`，对象名称字号 11 调至 12。
- 空间拖入接纳：对象拖出后可再拖回，落点在空间内即放入并自动整理成员。
- 空间手动调框：选中空间拖四角可拉大/缩小框，成员进出仍按内容自动贴合。
- 单实例运行：重复启动只激活已有窗口，不再开多个实例。

## v0.1.0（2026-10-25）

首个公开版本：把文件、截图、文字、URL 放到一张无限画布上，分组、连线、标注、搜索定位；只保存引用，原文件不动。

- **导入**：拖入 / 粘贴文件、文件夹、文字、URL、截图；按真实路径去重，重复导入自动定位。
- **组织**：无限画布平移缩放、框选多选、空间（分组框）、拖动对齐吸附、对象与空间不重叠、空间自动整理。
- **关系**：有向连线（锚点拖拽、批量连线、标签、取色），右键跳转关联对象。
- **标注**：多选批量标注，空间标题即标注。
- **搜索**：拼音首字母 + 模糊搜索，覆盖对象、标注、空间标题与连线标签，回车直接定位。
- **文件**：双击用系统默认程序打开、资源管理器中定位、Windows 原生 Shell 右键菜单（含第三方扩展）、缺失文件校验与重新关联。
- **外观**：四套浅色主题；窗口最小化自动暂停渲染。
- **隐私**：纯本地运行，无云端、无遥测、无外部请求。
